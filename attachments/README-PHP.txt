REMÉDIOS DA VOVÓ - VERSÃO PHP

Todos os arquivos HTML do projeto foram convertidos para PHP.
Os links internos .html também foram alterados para .php.

Estrutura principal:
- index.php
- cadastro.php
- carrinho.php
- faleConosco.php
- login.php
- pagamento.php
- produto.php
- produtos.php
- usuario.php

CSS, JavaScript e imagens foram mantidos em assets/ para preservar o layout e as funcionalidades existentes.

IMPORTANTE:
Esta conversão transforma as páginas em arquivos PHP, mas o projeto ainda usa localStorage em algumas funcionalidades JavaScript (login, carrinho e pedidos). Para um sistema PHP completo com banco de dados, será necessário integrar MySQL/PDO e autenticação no servidor.
